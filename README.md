## 💻 हे प्रोजेक्ट कसे चालू करावे (How to Run)

1. `index.html` फाईलवर **Double Click** करा, ती थेट तुमच्या Google Chrome किंवा कोणत्याही ब्राऊझरमध्ये उघडेल.
2. किंवा VS Code मध्ये हे फोल्डर ओपन करून **Live Server** extension द्वारे `Go Live` करा.

## 🌐 मोफत लाईव्ह होस्ट कसे करावे (Free Hosting)

### पर्याय १: GitHub Pages वर
1. तुमच्या GitHub खात्यावर एक नवीन repository तयार करा (उदा. `portfolio`).
2. या फोल्डरमधील सर्व फाईल्स (`index.html`, `style.css`, `script.js`, `assets`) तिथे पुश/अपलोड करा.
3. Repository Settings -> **Pages** मध्ये जा -> Branch: `main` निवडून **Save** करा.
4. तुमची वेबसाईट `https://your-username.github.io/portfolio` वर लगेच लाईव्ह होईल!

### पर्याय २: Vercel / Netlify वर
- [vercel.com](https://vercel.com) किंवा [netlify.com](https://netlify.com) वर जाऊन फक्त हे फोल्डर Drag & Drop करा; तुमची वेबसाईट १ मिनिटात लाईव्ह होईल.
